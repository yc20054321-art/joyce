# 資料夾索引

原本所有檔案都平放在同一層,現已依用途分成「投資理財」與「照片」兩大類。

## 📊 投資理財

每份資料都有兩個版本:
- `xxx.csv` — 一般 UTF-8,適合程式讀取
- `xxx_excel.csv` — 含 BOM,用 Excel 直接打開中文不會變亂碼

內容完全相同,只差編碼。

| 資料夾 | 內容 |
|---|---|
| `01_我的持股` | 我自己的持股總表、獲利部位、虧損部位 |
| `02_換股與調整` | 換股候選評估、換股執行清單、建議配置 |
| `03_朋友投資組合` | 朋友的原始持股、重整方案 A/B/C、加碼與新股方向、最終定案 |
| `04_個股與產業研究` | 鴻海 2317、panjit 2481、上詮 3363 財報整理,官股金控對照表 |
| `05_行動計畫與檢核` | 6/8 大跌應對計畫、基金轉換前該問理專的檢核表 |

### 各檔案說明

**01_我的持股**
- `portfolio` — 完整持股(代號、股數、均價、成本、現價、市值、損益、體質分類)
- `portfolio_winners` — 獲利中的部位
- `portfolio_losers` — 虧損中的部位

**02_換股與調整**
- `swap_evaluation` — 候選買進/賣出標的評估(產業、風險、重疊度、評等、建議動作)
- `swap_execution` — 實際換股執行清單
- `recommended_portfolio` — 建議的目標配置

**03_朋友投資組合**
- `friend_raw` — 朋友給的原始持股資料
- `friend_portfolio` — 整理後的持股總表
- `friend_A_taicement` / `friend_B_rebalance` / `friend_C_recommended` — 三種調整方案
- `friend_redeploy` — 資金重新配置
- `friend_stock_addons` — 加碼標的
- `friend_newstock_direction` — 新股布局方向
- `friend_final_plan` — 最終定案

**04_個股與產業研究**
- `honhai_2317_financials` — 鴻海財報
- `panjit_2481_financials` — panjit 財報
- `shangchuan_3363_financials` — 上詮財報
- `gov_financial_holdings` — 兆豐金/華南金/第一金/合庫金 存股比較

**05_行動計畫與檢核**
- `0608_action_plan` — 6/8 市場大跌的心態與操作對策
- `fund_switch_checklist` — 理專推薦轉換基金時,該問哪些問題
