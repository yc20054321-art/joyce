## 欄位口徑（重要）

| 用語 | 定義 |
|---|---|
| 成本金額 | 股數 × 均價／成本價 |
| 市值 | 股數 × 現價 |
| 損益(%) | (市值 − 成本金額) ÷ 成本金額 |
| 現價 | **快照當天的收盤價，不是即時價**——超過快照日就已過期 |
| 「待查」 | 該欄尚未查證，**不是 0、不是沒有**，不可當成事實引用 |
| 「─」 | 該欄不適用（多半是表格的分隔列） |
| 佔比(%) | 該檔市值 ÷ 該組合總市值 |

**所有金額單位為新台幣元。** 兩份組合互相獨立，數字不可混用。

## 讀表注意事項

1. **friend_redeploy / friend_stock_addons / friend_newstock_direction 是不規則表**——
   中間有 `─` 分隔列，把「建議加碼」和「避免加碼」兩個區塊塞在同一個檔裡。
   程式讀取時要先切區塊，不要當成單一矩形表格。
2. **swap_evaluation.csv 有 3 個「待查」欄位**（殖利率、本益比、月營收趨勢）全部未填。
3. **價格會過期。** 引用任何現價、市值、損益前，先看快照日；超過就要標明是舊資料。
4. **不要跨組合合併統計**——兩份是不同人的帳戶。
