# 副採章節投影片產生器

在既有的《業務工作範疇說明》簡報（V6，2026-09-02 版）中，插入「三、副採」三張投影片，
並將原本的「三、A 部現況」「四、結論」順延為「四」「五」，同時更新封面目錄。

## 檔案

| 檔案 | 用途 |
|---|---|
| `gen.py` | 依原簡報的設計語彙（色票、字級、欄距）產生三張副採投影片，並完成 package 註冊 |
| `renumber.py` | 更新封面目錄，並將後續章節編號順延 |
| `build.sh` | 解壓 `src.pptx` → 產生 → 重新打包 → 驗證，一次跑完 |

## 使用方式

把原始簡報放在與腳本同一層、命名為 `src.pptx`，然後：

```bash
bash build.sh      # 產出 out.pptx
```

## 設計語彙（取自原簡報）

- 版面 13.333" × 7.5"；內容區 x=0.62、寬 12.09；左側 0.16" 深藍直條
- 色票：`1C4F8F` 深藍／`2A78D6` 亮藍／`0B0B0B` 標題黑／`454441` 內文／`898781` 註記
  ／`F4F6F9` 面板／`E8F1FC` 結語底／`D03B3B`＋`FDEFEF` 強調
- 字級：章節眉標 12.5pt、標題 25pt、區塊標 12.5pt、卡片標 10.5pt、內文 9.5–10pt、來源 8.5pt
- 字體：微軟正黑體
