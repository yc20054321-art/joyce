# 主採／副採章節投影片產生器

在既有的《業務工作範疇說明》簡報（V6，2026-09-02 版，15 頁）中，插入兩個新章節共六張投影片：

- **三、主採**（3 頁）— 來源：《主採工作內容分類與 AI 可行性分析》綜合分析表
- **四、副採**（3 頁）— 來源：副採業務工作範疇口述盤點

並將原本的「三、A 部現況」「四、結論」順延為「五」「六」，同時更新封面目錄。
產出 21 頁。

## 檔案

| 檔案 | 用途 |
|---|---|
| `gen.py` | 依原簡報的設計語彙（色票、字級、欄距）產生六張投影片，並完成 package 註冊 |
| `renumber.py` | 更新封面目錄，並將後續章節編號順延 |
| `build.sh` | 解壓 `src.pptx` → 產生 → 重新打包 → 驗證，一次跑完 |

## 使用方式

把原始簡報放在與腳本同一層、命名為 `src.pptx`，然後：

```bash
bash build.sh      # 產出 out.pptx
```

## 設計語彙（取自原簡報）

- 版面 13.333" x 7.5"；內容區 x=0.62、寬 12.09；左側 0.16" 深藍直條
- 色票：`1C4F8F` 深藍／`2A78D6` 亮藍／`0B0B0B` 標題黑／`454441` 內文／`898781` 註記
  ／`F4F6F9` 面板／`E8F1FC` 結語底／`D03B3B`＋`FDEFEF` 強調（沿用原簡報第 8 頁「⑦ 例外應變」的紅色處理）
- 字級：章節眉標 12.5pt、標題 25pt、區塊標 12.5pt、卡片標 10.5pt、內文 9-10pt、來源 8.5pt
- 字體：微軟正黑體
- 每頁結構：眉標 → 標題 → 分隔線 → 內容 → 淺藍結語帶「→ …」→ 灰色資料來源

## 數字口徑

主採章節的信件數與占比引自來源表，該表自述樣本僅涵蓋一人信箱可見範圍、
占比為關鍵字分類估算值；此限制已完整保留在第 13 頁的「⚠ 數字口徑」區塊與各頁資料來源行。
